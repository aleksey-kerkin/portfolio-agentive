# Agentive: лендинг ИИ-SaaS (вёрстка по макету Figma)

Проект для портфолио: адаптивная вёрстка лендинга по бесплатному шаблону Figma Community «Agentive, AI SaaS Landing». Тексты переведены на русский.

## Стек
- React 18 + TypeScript (strict)
- Vite 5
- Tailwind CSS 3 (брейкпоинты: мобильный 390, `md` 768, `lg` 1024, `xl` 1440)
- Шрифты: Onest (заголовки, замена Bricolage Grotesque из макета, у которого нет кириллицы), Inter (текст), Google Fonts

## Запуск
```bash
npm install
npm run dev        # режим разработки
npm run typecheck  # проверка типов (tsc)
npm run build      # продакшен-сборка в dist/
npm run preview    # просмотр сборки
```

## Что реализовано
- Шапка: на мобильных бургер-меню (aria-expanded, закрытие по Esc)
- Первый экран с «плавающими» карточками агентов (анимация, отключается при prefers-reduced-motion)
- Полоса логотипов, блок статистики
- 4 карточки возможностей (bento-сетка)
- Тёмная «живая» панель: прогресс агентов и лента событий обновляются в реальном времени, переключение групп
- Сценарии использования: табы по WAI-ARIA, управление стрелками
- Отзывы с карточкой-метрикой
- Тарифы с переключателем «помесячно / за год» (скидка 20% пересчитывается)
- Финальный CTA и подвал
- Семантика (section, nav, figure/blockquote, dl), alt, focus-состояния, skip-link
- Без горизонтального скролла от 320 до 1920 px
